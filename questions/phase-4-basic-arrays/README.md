# Phase 4 – Basic Arrays (Iterative Logical Thinking)

Focus on storing, processing, and transforming collections of data.

## Questions

1. Store 5 numbers in an array and print them.
2. Find the largest element in an array.
3. Find the smallest element in an array.
4. Calculate the sum of elements in an array.
5. Find the average of array elements.
6. Count how many even numbers are in an array.
7. Count how many odd numbers are in an array.
8. Search for an element in an array.
9. Find the second largest element in an array.
10. Reverse the elements of an array.
11. Check if an array contains duplicate values.
12. Sort an array in ascending order.
13. Sort an array in descending order.
14. Find the frequency of each number in an array.
15. Find the sum of even-indexed elements.
16. Find the sum of odd-indexed elements.
17. Print only positive numbers from an array.
18. Merge two arrays into one array.
19. Find the missing number in a sequence.
20. Check if an array is symmetric.

## Extra Challenges

- Rotate an array to the left by k positions.
- Remove duplicates from an array.
- Find pairs that sum to a target value.
- Find the maximum subarray sum.
- Implement basic matrix addition using arrays.
