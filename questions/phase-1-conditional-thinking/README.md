# Phase 1 – Conditional Thinking (If–Else, Boolean Logic)

Practice these questions to improve decision-making and boolean logic.

## Questions

1. Write a program to check whether a number is positive, negative, or zero.
2. Take three numbers and print the greatest among them.
3. Check whether a year is a leap year.
4. Write a program to determine if a person is eligible to vote.
5. Take two numbers and check if they are equal or different.
6. Write a program to check whether a number is divisible by 2, 3, and 5.
7. Given a character, check whether it is a vowel or consonant.
8. Check whether a triangle is valid using side lengths.
9. Find the grade of a student based on marks: A, B, C, D, F.
10. Check whether a number is odd or even.
11. Write a program to determine if a number is prime.
12. Check whether a given year is a century year.
13. Determine whether a person is eligible for a discount based on age and membership.
14. Check if a string is empty or not.
15. Given three sides, determine whether the triangle is equilateral, isosceles, or scalene.
16. Write a logic to check whether a password is strong based on length and character conditions.
17. Check whether a number is within a range between 10 and 100.
18. Find whether a student passes when marks are above 40 in all subjects.
19. Write a program to compare two strings lexicographically.
20. Check if a day is a weekday or weekend.

## Extra Challenges

- Build a calculator with +, -, *, / operations using conditions.
- Create a menu-driven program for a small shop.
- Check if a given date is valid.
- Determine if a student is eligible for scholarship based on marks and attendance.
- Build logic for a simple ATM withdrawal system.
