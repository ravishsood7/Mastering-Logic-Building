# Phase 3 – Recursion (Thinking in Self-Reference)

Focus on breaking a problem into smaller versions of itself.

## Questions

1. Write a recursive function to print numbers from 1 to n.
2. Write a recursive function to print numbers from n to 1.
3. Find the factorial of a number using recursion.
4. Calculate the sum of first n natural numbers recursively.
5. Find the nth Fibonacci number using recursion.
6. Check whether a number is even using recursion.
7. Find the power of a number using recursion.
8. Reverse a number using recursion.
9. Find the sum of digits of a number using recursion.
10. Check whether a string is a palindrome using recursion.
11. Print a recursive countdown timer.
12. Find the greatest common divisor (GCD) using recursion.
13. Write a recursive function to print a triangle pattern.
14. Compute the product of numbers from 1 to n recursively.
15. Find the number of digits in a number using recursion.
16. Reverse an array using recursion.
17. Search for an element in an array using recursion.
18. Generate Pascal's triangle row recursively.
19. Implement binary search recursively.
20. Create a recursive function to print all divisors of a number.

## Extra Challenges

- Solve Tower of Hanoi using recursion.
- Print nested parentheses patterns recursively.
- Find the count of vowels in a string using recursion.
- Implement recursive merge sort logic.
- Build a recursive directory traversal simulation.
