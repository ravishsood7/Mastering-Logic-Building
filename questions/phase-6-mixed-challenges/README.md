# Phase 6 – Mixed Logical Challenges (Applied Reasoning)

These questions combine multiple concepts and are useful for real problem-solving practice.

## Questions

1. Write a program to check whether a number is prime and also even.
2. Create a program to calculate the factorial of a number and print whether it is odd or even.
3. Check if a string is a palindrome and also contains only letters.
4. Find the frequency of each element in an array and then sort it.
5. Write a program to check if a number is Armstrong number.
6. Check whether a list contains duplicates after removing the first occurrence.
7. Find the sum of digits in a number and determine if the result is divisible by 3.
8. Generate a pattern using loops and then validate the number of rows.
9. Find the longest palindrome in a sentence using string logic.
10. Write a program to reverse a string and then check whether it is equal to the original.
11. Create a simple student management system using conditions and loops.
12. Find the most frequent character in a string and count its occurrences.
13. Check whether an array is sorted in ascending order.
14. Implement a menu-driven calculator that handles invalid input gracefully.
15. Find all prime numbers in a range and display their count.
16. Compare two arrays and print common elements.
17. Create a number guessing game with hints like greater or smaller.
18. Validate a username using conditions and string checks.
19. Write a logic to count vowels, consonants, and spaces in a sentence.
20. Create a mini billing system using conditions, loops, and arrays.
