# Phase 5 – Strings (Basic Logic Building)

Practice text manipulation, pattern checks, and string logic.

## Questions

1. Check whether a string is palindrome.
2. Reverse a string.
3. Count the number of vowels in a string.
4. Count the number of consonants in a string.
5. Check whether a string contains only digits.
6. Check whether a string contains only alphabets.
7. Find the length of a string without using built-in functions.
8. Count the frequency of each character in a string.
9. Remove spaces from a string.
10. Find the first and last character of a string.
11. Convert a string to uppercase.
12. Convert a string to lowercase.
13. Check whether two strings are anagrams.
14. Find the common characters between two strings.
15. Replace all occurrences of a character in a string.
16. Check whether a string starts and ends with the same character.
17. Find the longest word in a sentence.
18. Count the number of words in a sentence.
19. Remove duplicate characters from a string.
20. Check whether a string is a valid email format.

## Extra Challenges

- Check whether a string is a valid password.
- Find the most repeated character in a string.
- Sort characters in a string alphabetically.
- Build a Caesar cipher logic.
- Validate a URL string.
