# Phase 2 – Looping & Patterns (Iteration & Flow)

Practice loops, repetition, and pattern generation.

## Questions

1. Print numbers from 1 to 10 using a loop.
2. Print even numbers from 1 to 50.
3. Print the multiplication table of a given number.
4. Calculate the sum of numbers from 1 to n.
5. Find the factorial of a number using a loop.
6. Print the reverse of a number using a loop.
7. Count how many digits are present in a number.
8. Print a pyramid pattern using stars.
9. Print an inverted triangle pattern.
10. Print a right-angle triangle pattern.
11. Print a diamond pattern.
12. Print the Fibonacci series up to n terms.
13. Print numbers in descending order from n to 1.
14. Find the sum of digits of a number.
15. Check whether a number is a palindrome using loop logic.
16. Print all prime numbers from 1 to 100.
17. Print a pattern with increasing numbers in each row.
18. Print a pattern with decreasing numbers in each row.
19. Write a program to print the ASCII values of characters.
20. Print a hollow rectangle pattern.

## Extra Challenges

- Create a butterfly pattern.
- Print a pattern of 1, 12, 123, 1234, etc.
- Build a number triangle using nested loops.
- Print the multiplication table from 1 to 10.
- Generate a checkerboard pattern using loops.
